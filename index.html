unTopGlobal Automation is a private tool built and used by one independent creator to manage his own channels on YouTube:

  • unTopGlobal
  • unTopGlobal TV
  • unTopGlobal Meta

What it does

It runs in Google Apps Script with the channel owner's own Google accounts (OAuth 2.0) and uses YouTube API Services to:

  • upload the owner's own Shorts and videos;
  • add captions, titles, descriptions and playlists to those videos;
  • post and reply to comments on the owner's own videos;
  • read the owner's own channel analytics to improve future content.

Who can use it

Only the channel owner. The tool is not offered to the public, has no sign-up, and does not access any third-party user or channel data.

Read how data is handled in the Privacy Policy and the rules of use in the Terms of Service. This tool uses YouTube API Services; by using it you agree to the YouTube Terms of Service.
