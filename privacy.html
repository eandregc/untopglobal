1. Who we are

unTopGlobal Automation is a private tool operated by an independent creator to manage his own YouTube channels (unTopGlobal, unTopGlobal TV and unTopGlobal Meta). It is not offered to other users.

2. Use of YouTube API Services

This tool uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. YouTube data is also handled according to the Google Privacy Policy.

3. What data we access

Only data of the owner's own channels, accessed with the owner's own Google accounts through OAuth 2.0:

  • the owner's videos and their metadata (titles, descriptions, captions, playlists);
  • comments posted on the owner's own videos (to reply to them);
  • aggregate analytics of the owner's channels (views, watch time, retention).

We do not access any data of third-party channels, and we do not collect personal information from viewers beyond the public comments shown on the owner's own videos.

4. How we use it

Only to publish and manage the owner's own content and to improve future videos. Data is never sold, shared with third parties, or used for advertising.

5. Storage and retention

  • Data is stored only in the owner's private Google account (Google Apps Script properties, Google Sheets and Google Drive).
  • Analytics and other data obtained from YouTube API Services are refreshed or deleted within 30 days, as required by the YouTube API Services Developer Policies.
  • Authorization tokens are kept only to operate the tool and are deleted when access is revoked.

6. Cookies

This tool does not place cookies on viewers' devices. This website does not use cookies or tracking.

7. Revoking access and deleting data

Access granted to this tool can be revoked at any time on the Google security settings page. To request the deletion of any stored data, write to the contact below; it will be deleted within 7 days.
